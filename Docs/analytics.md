# Analytics & Performance Monitoring

Metrics tracking strategy:

- **Google Analytics (GA4):** User pageviews, session duration, referral traffic tracking.
- **Search Console:** Indexing status, keyword ranking, and click-through rates.
- **Hotjar / Heatmaps:** User scroll depth and click interaction heatmaps.
- **Visitor Tracking:** Anonymous visitor analytics.
- **Performance Monitoring:** Real user monitoring (RUM) for Core Web Vitals metrics.
