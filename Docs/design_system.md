# Design System

UI Component Design System & Tokens:

- **Spacing Scale:** 4px, 8px, 16px, 24px, 32px, 48px, 64px
- **Grid Layout:** 12-column responsive fluid grid
- **Cards & Glassmorphism:** Subtle background blur, 1px border gradient, 16px border-radius
- **Buttons:** Primary gradient action buttons, secondary outlined buttons, icon buttons
- **Inputs & Forms:** Floating label input fields with active focus rings
- **Navbar & Footer:** Sticky glassmorphic header navigation & structured footer
- **Icons:** SVG vector iconography with theme dynamic fill
- **Border Radius:** 4px (sm), 8px (md), 16px (lg), 9999px (pill)
- **Shadows:** Soft elevation shadows with dark/light theme adaptations
