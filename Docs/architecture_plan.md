# Architecture Plan

Visual component layout and tree hierarchy for the portfolio application:

```text
App (Root Component)
│
├── Navigation Bar (Header & Theme Toggle)
│
├── Home Page Container
│   ├── Hero Section (Title, Subtitle, CTA, Resume Button, GitHub Link)
│   ├── About Section (Career Objective, Bio, Experience Counter)
│   ├── Skills Section (Languages, Flutter, State Management, Databases, Tools)
│   ├── Experience Section (Timeline, Roles, Technologies, Impact)
│   ├── Projects Section (Bento Grid: MedBridge, Virtual Care, Task Manager, E-Commerce, etc.)
│   ├── Education & Certifications Section (Degrees, Ostad/BIDA/Google Certs)
│   ├── Achievements & Testimonials Section (Hackathons, Awards, Client Quotes)
│   └── Contact Section (Form, Direct Phone/Email, Location)
│
└── Footer Component (Social Links & Copyright)
```
