# Asset Management Specifications

Asset categories and file formats:

- **Images & Screenshots:** WebP format optimized for high-density mobile screens.
- **Icons & Logos:** SVG vector graphics.
- **Certificates:** High-resolution scans stored in `/assets/certificates/`.
- **Resume:** PDF format stored in `/assets/resume/sifat_khan_joy_resume.pdf`.
- **Project Screenshots:** Categorized by project folder (`/assets/projects/medbridge/`, `/assets/projects/virtual-care/`, etc.).
