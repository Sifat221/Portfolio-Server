# Flutter Developer Portfolio

Modern, high-performance, production-ready portfolio application showcasing Flutter engineering expertise, featured mobile & web applications, certifications, and technical experience.

## Overview
This repository contains the complete codebase, design system specifications, dynamic datasets, and architecture for a premium personal portfolio website and API backend.

## Key Features
- **Responsive Layout:** Optimized across Mobile, Tablet, Laptop, and Ultra-Wide Desktop displays.
- **Theme Customizer:** Dynamic Dark and Light mode support.
- **Project Bento Grid:** Showcase of flagship mobile projects with filterable tags and modal case studies.
- **Interactive Contact Gateway:** Live contact form backed by Node.js server email delivery.
- **SEO & Web Performance:** Optimized meta tags, OpenGraph cards, JSON-LD structured data, and Lighthouse 95+ score.

## Tech Stack
- **Frontend / Client:** HTML5, Modern JavaScript (ES6+), Vanilla CSS Token System
- **Mobile Stack Showcase:** Flutter, Dart, BLoC / Cubit, Provider, Riverpod, Firebase, REST APIs
- **Backend Server:** Node.js, Express.js framework
- **Data & Assets:** Structured JSON datasets (`/data`) and asset pipeline (`/assets`)

## Installation & Setup
```bash
# Clone the project repository
git clone https://github.com/SifatKhanJoy/Server.git
cd Server

# Install dependencies
npm install

# Start development server
npm run dev
```

## Folder Structure
```
├── Docs/           # Complete project documentation (32 files)
├── assets/         # Images, project screenshots, logos, certificates
├── data/           # JSON datasets (personal, projects, skills, etc.)
├── client/         # Portfolio web app source code
└── server/         # Express API server source code
```

## Deployment
Deployed using continuous integration on GitHub Pages / Vercel (Frontend) and Render / Railway (Backend API).
