# Project Brief

## Project Vision
To design and build a state-of-the-art, scalable, interactive portfolio website that highlights Sifat Khan Joy's proficiency as a professional Flutter & Mobile Application Developer.

## Goals
1. Showcase flagship mobile apps (MedBridge, Virtual Care, Task Manager, E-Commerce, Shop Management, House Rental, PetPassion).
2. Highlight specialized Flutter skills (BLoC/Cubit, Riverpod, Custom Animations, REST API integration, Firebase).
3. Provide recruiters, clients, and engineering leads with a seamless user experience, quick resume download, and direct communication channel.

## Target Audience
- Technical Recruiters & Engineering Hiring Managers
- International & Local Mobile App Clients
- Peer Software Engineers & Open Source Community

## Purpose & Scope
Single-page application (SPA) with modal case study views, dynamic JSON data loading, responsive layout, dark/light theme toggle, and backend mail service.

## Timeline & Deliverables
- **Timeline:** 6 Development Phases (Planning $\rightarrow$ Design $\rightarrow$ Development $\rightarrow$ Testing $\rightarrow$ Optimization $\rightarrow$ Deployment)
- **Deliverables:** Fully functional portfolio, complete documentation suite, structured JSON data API, production deployment.
