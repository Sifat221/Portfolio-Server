# Final Specification

The portfolio must fulfill all of the following core requirements:

## Core Features & Requirements

1. **Responsive Design:** Flawless rendering across Mobile (<640px), Tablet (640px-1024px), Laptop (1024px-1280px), and Desktop (>1280px).
2. **Dark & Light Mode:** Toggleable color themes using HSL CSS design tokens.
3. **SEO Optimization:** Full meta tags, OpenGraph cards, Twitter preview cards, and JSON-LD structured data.
4. **Accessibility (WCAG 2.1 AA):** ARIA labels, semantic HTML5, keyboard focus indicators, 4.5:1 color contrast.
5. **Animations & Micro-interactions:** Smooth scroll reveals, card hover transforms, glassmorphism glow effects.
6. **Contact Form:** Form validation with asynchronous backend submit API (`POST /api/contact`) and email notifications.
7. **GitHub Integration:** Dynamic link to live code repositories and open-source stats.
8. **Resume Download:** Single-click direct PDF download action.
9. **Fast Performance:** Target 95+ score on Google Lighthouse across Performance, Accessibility, and SEO.
10. **Production Ready:** Zero console warnings, clean code architecture, fully validated data schemas.
