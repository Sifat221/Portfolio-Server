# Accessibility Standards (WCAG 2.1 AA)

Accessibility implementations:

- **ARIA Attributes:** Full ARIA markup on modals, tab switches, and contact form inputs.
- **Keyboard Navigation:** Complete tab index support and visual focus outlines.
- **Color Contrast:** Minimum 4.5:1 ratio across text elements in both Dark and Light themes.
- **Focus States:** High contrast focus rings (`outline: 2px solid var(--color-primary)`).
- **Screen Reader Support:** Semantic HTML tag hierarchy (`header`, `nav`, `main`, `section`, `article`, `footer`).
