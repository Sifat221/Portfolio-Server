# Responsiveness Guidelines

Breakpoint rules and layout behaviors:

- **Mobile (<640px):** Single column stream, sticky collapsible mobile navbar, full-width buttons.
- **Tablet (640px - 1024px):** 2-column bento project grid, compressed timeline layout.
- **Laptop (1024px - 1280px):** 3-column project showcase, side-by-side About/Hero presentation.
- **Desktop (>1280px):** Max container width 1200px centered with multi-column layout.

## Responsive Rules
- No horizontal scrolling (`overflow-x: hidden`).
- Touch target sizes minimum 48x48px on mobile devices.
